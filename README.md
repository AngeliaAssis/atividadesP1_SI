# 📚 Atividades Práticas — Scripts e Automações

Este repositório contém atividades práticas desenvolvidas para a disciplina de **Sistemas da Informação**, com foco no aprendizado e aplicação de **scripts e automações** em diferentes linguagens de programação.

---

## 🎯 Objetivo

O principal objetivo dos exercícios foi praticar conceitos fundamentais de:

- Lógica de programação
- Estruturas de decisão e repetição
- Manipulação de arquivos
- Automação de tarefas no sistema operacional
- Interação com o usuário
- Integração com recursos do sistema (voz, teclado e execução de aplicativos)

---

## 💻 Linguagens utilizadas e estrutura dos exercícios

- Scripts em **VBScript** para lógica básica e jogos simples
- Scripts em **Batch** para automação no Windows e menus interativos
- Script em **Python** para automação avançada com integração de voz

---

## 🧠 Aprendizados

Com essas atividades foi possível desenvolver habilidades como:

- Pensamento lógico e estruturado
- Automação de tarefas do sistema
- Integração entre software e hardware (microfone/voz)
- Organização de código em funções
- Criação de fluxos interativos para usuário

---

## 👨‍💻 Autor

Atividades desenvolvidas como prática acadêmica na disciplina de **Sistemas da Informação**.

---

## 📌 Observação

Todos os scripts foram criados com fins educacionais, focados no aprendizado de lógica de programação e automação de sistemas operacionais.
